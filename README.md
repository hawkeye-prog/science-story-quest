# Science Story Quest

A reading, writing, grammar and spelling app for young readers (about age 10), built as a single HTML file.

- **36 science stories** (space, Earth, animals, plants, the human body, physics, chemistry, technology), each with reading questions, written answers checked for ideas, spelling and grammar, fix-the-sentence editing, and typed spelling (listen & spell, word detective).
- **Gamified:** XP and levels, gems, streaks, badges, a sticker shop and a word bank.
- **The Spellbound Scholar:** a 36-chapter wizard adventure. Each finished story challenge earns an adventure ticket for the next chapter. Spells are learned with gems earned from reading and are cast by typing words from the stories.

Progress is saved in the browser (localStorage) on the device where it is played.

Play it: open `index.html` in any modern browser, or visit the GitHub Pages site for this repository.
